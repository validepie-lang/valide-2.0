## Regra de tamanho

Uma issue cabe em uma sessão de trabalho. Se não cabe, é SPEC disfarçada de issue.

Exemplos de issue boa:

- `001-tipos-e-mocks-importacao.md`
- `002-componente-column-mapper.md`
- `007-estados-vazios-do-estoque.md`

Exemplos de issue ruim:

- "Criar a tela de importação" (é a SPEC inteira)
- "Melhorar o dashboard" (não tem critério de aceite possível)
- "Ajustes gerais" (não tem escopo)
